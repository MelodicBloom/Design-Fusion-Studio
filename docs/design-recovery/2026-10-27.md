## Repository-specific records

### D23 — Design Fusion Studio: a comparative aesthetic lexicon and safe commerce boundary

**Use when:** When developing Design Fusion Studio, style/layout hybrids, component export, aesthetic comparison, or premium code delivery.

[Recovered intent] replit.md calls the app Aesthetic Lexicon: ten styles, ten layouts, three hybrids, and ten interactive themed components with sound. The actual mock-data source grounds visual families in paper-art imagery: Mosaic Horizon, Amber Tides, Crimson Beacon, Amethyst Peaks, Cosmic Swirl, and further palettes/traits.

[Design DNA] Preserve image-derived color, dimensional paper/quilling structure, distinct layout grammar, preview comparison, and useful code inspection. A hybrid needs an explanation of which rules survive and which conflict—not an average of two palettes.

[Observed implementation concern] The inspected POST /api/purchases records an unlock from client-supplied sessionId/layoutId; it does not verify a payment in that route. This is a prototype unlock mechanism, not demonstrated purchase entitlement.

[Repair resolution — proposed] Separate demo unlock from commercial entitlement. Use a real server-verified checkout/webhook/entitlement adapter before advertising paid source delivery. Independently model Style, Layout, Component, HybridRule, PreviewFixture, ExportBundle, and license. Audit whether the preview and delivered code actually match.

[Reimagined horizon] A comparative design studio that teaches material/layout composition, generates explainable hybrids, and exports useful components with provenance. It can serve as a product or a consultation instrument.

[Carry-forward test] One hybrid preserves declared invariants, renders at mobile/desktop, exports the actual source shown, and can be used in a fresh consumer. A forged or replayed prototype session cannot grant a real paid entitlement.
